# Roadmap

## Current foundation

Intake, performance measurement, document guidance, scoped permissions, recoverable writes, notification state tracking, and logical restore are implemented with local simulated-service tests.

## Before operational use

1. Qualify real Google identity, file access, triggers, concurrency, quotas, delivery, and restore in an isolated test Workspace.
2. Complete customer/contact relationships and the tracked improvement-action lifecycle.
3. Finish template provisioning, import validation, reporting, and administrator handover.
4. Measure capacity and response times with representative synthetic workloads.
5. Complete a bounded pilot with explicit acceptance and recovery checks.

User counts and performance targets in the qualification checklist are hypotheses until measured.
The current project does not claim production readiness, validated demand, or a finished commercial service.
